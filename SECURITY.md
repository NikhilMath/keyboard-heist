# Security

## Reporting a problem

If you find a security issue in Keyboard Heist or on keyboardheist.com, please report it privately to the owner, Nikhil Math. **Don't open a public issue.**

1. **Preferred:** use GitHub's private reporting at https://github.com/NikhilMath/keyboard-heist/security/advisories/new
2. **Or:** get in touch through https://nikhilmath.com

Please include:

- what you found
- the steps to reproduce it
- what someone could do with it

You'll get a reply as soon as possible. Please give the owner a reasonable amount of time to fix the issue before you talk about it publicly.

## What's covered

The game is a static website: one HTML page, one stylesheet and some images. It has no accounts, no server code and no database, and it only saves your progress in your own browser. Reports about the site's code, its hosting, or anything that could affect players are welcome.

## Supported versions

Only the current version on the `main` branch (the one live at https://keyboardheist.com) receives fixes.
